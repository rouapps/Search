# IdeaCompass 🧭

A live, cited market intelligence engine for founders & investors that uses reference-class forecasting to provide probabilistic outcome estimates.

## Quick Start

1. **Get a Perplexity API key** from https://www.perplexity.ai/settings/api

2. **Set up your API key:**
   ```bash
   ./setup-api-key.sh
   ```

3. **Start the application:**
   ```bash
   ./start.sh
   ```

4. **Open your browser:** http://localhost:3000

## Requirements

- Python 3.9+
- Node.js 18+
- Perplexity API key
